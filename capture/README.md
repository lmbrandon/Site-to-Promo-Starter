# capture/

**Step 1 output.** Screenshots, page text, logo and product images collected from the website you are allowed to feature.

Typical contents (all git-ignored):

- `page-1.png`, `page-2.png`, ...: 1920x1080 screenshots of key pages (home, features, pricing, proof)
- `img*.jpg`: product/feature images, hero art and the logo
- `visible-text.txt`: the value proposition, headline number, price and feature list

Only capture sites you own or have written permission to feature. Do not keep private people's names, faces or messages.
